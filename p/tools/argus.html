ARGUS — Active Directory Visibility Framework

ARGUS is a modular Active Directory visibility and security review framework written in Go. It is built to surface privilege exposure, Kerberos weaknesses, dangerous ACL paths, delegation risks, PKI issues, service-account impact, and domain controller attack surface from a defender-oriented perspective.

Active Directory Go Windows Security Review Kerberos ACL Analysis Delegation AD CS Tier 0 Cross-Platform Releases

Key Findings

  • Broad module coverage: inventory, exposure review, privilege mapping, delegation, ACL review, PKI review, and consolidated core assessment.
  • Productized workflow: branded CLI, HTML reporting, embedded logo assets, release packaging, and cross-platform binaries.
  • Defender focus: prioritizes blast radius, privilege concentration, service-account dependency, and domain controller exposure.
  • Documentation-first design: repository documentation and per-module screenshots support both portfolio presentation and project walkthrough.
